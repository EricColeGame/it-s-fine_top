## Progression on Screen: Sleephours, Dreamtree, and Evolving Stations

The core loop starts with coding and upgrading your development operation. Each station can introduce its own resource or mechanic, so the smart play is rarely the biggest visible upgrade. In footage, watch for the moment a player chooses an unlock that broadens their options instead of deepening a single production line. That choice usually defines how the rest of the run unfolds.

The prestige system is built around sleep. Sleeping generates Sleephours, described in the game's own framing as one of the most valuable currencies an indie developer can have. Those hours go into the Dreamtree, which grants permanent meta-upgrades, new mechanics, and effects that persist across runs. Watching someone time their first sleep decision is genuinely instructive, because it is the pivot point where a run stops being about today's numbers.

| System | Function | Practical priority |
| --- | --- | --- |
| Coding | Main development activity | Establish the first reliable source of progress |
| Upgrade stations | Add resources and mechanical effects | Favor unlocks that broaden the run |
| Sleep | Generates Sleephours | Use when permanent progress beats short-term gains |
| Dreamtree | Permanent meta-progression | Invest in upgrades that improve future runs |
| Challenges | Optional goals and special effects | Attempt after the basic loop clicks |
| Alternate endings | Additional completion targets | Explore once more systems are unlocked |

Some mechanics are deliberately strange, and they are the moments that make an It's Fine gameplay video fun to watch. A botfarm generates wishlists for the marketing team. A Voodoo Kraken introduces its own system. Peanut, a squirrel tied to clean energy, can evolve into a more chaotic lightning-themed form. Community reports suggest these evolutions are easy to miss on a first run, which is exactly why footage helps.

A practical way to structure what you learn from a video is to think in three phases:

- **Foundation:** Build basic production and identify which station is limiting you.
- **Expansion:** Unlock mechanics that add new resources, effects, or automation.
- **Conversion:** Decide whether more short-term output beats sleeping for Dreamtree progress.

Progression tip: when a permanent unlock changes *how* a run works, it is usually worth more than several small upgrades to a resource you already produce.
