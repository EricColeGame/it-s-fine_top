### Three Rules That Keep a Run Healthy

- **Buy breadth before depth.** If two upgrades cost about the same, take the one that introduces something you've never seen. New resource types tend to open new stations, and new stations tend to open automation.
- **Watch the bottleneck.** Find the single station currently limiting your growth, fix that, then reassess. Chasing whatever looks impressive usually leaves the real constraint untouched.
- **Bank before a wall.** When progress slows to a crawl, continued production is worth less than the permanent gain waiting on the other side of a sleep.

A common pattern in player experience is that the mid-run slowdown isn't caused by weak upgrades — it's caused by an unexplored mechanic sitting one click away. If your numbers flatten, scan your station list for anything you haven't touched yet before you buy another multiplier.

## Sleephours, Dreamtree, and Permanent Automation Gains

Sleep is how It's Fine handles prestige. Instead of resetting for a flat multiplier, you convert a productive run into Sleephours, described in-game as one of the most valuable currencies an indie developer can have. Those hours go into the Dreamtree, which grants permanent meta-upgrades, unlocks new mechanics, and applies effects that carry across every future attempt.

| Signal in your run | What it suggests | Recommended move |
| --- | --- | --- |
| Production slowing sharply | Diminishing returns on current stations | Sleep and bank Sleephours |
| Fresh station unlocked but untouched | Unrealized value still on the table | Push one more layer before sleeping |
| Dreamtree node nearly affordable | Permanent gain within reach | Prestige now rather than later |
| Challenge objective almost complete | Optional reward at risk | Finish it before you sleep |
| First run, still learning systems | Low information, low output | Keep going until you understand the loop |

The classic mistake is sleeping out of curiosity too early. A run that ends before you've explored its new mechanics produces very little to invest, and you'll repeat the same shallow loop on the next attempt. The stronger habit is to push until your current run is genuinely exhausted, then convert that accumulated progress into permanent strength.

Because Dreamtree upgrades persist, each sleep should make the following run noticeably different — faster early production, cheaper stations, or entirely new options. If a new run feels identical to the last one, you invested too broadly instead of targeting the mechanic that was actually slowing you down.

## A Three-Phase Automation Run Plan

Dividing each run into three phases keeps decisions simple and prevents the two most common failures: over-investing in one resource and prestiging before a run has paid for itself.

| Phase | Goal | Checklist |
| --- | --- | --- |
| Foundation | Get reliable production running | Identify your current bottleneck; buy the first stations that add a new resource |
| Expansion | Broaden what the run can do | Unlock mechanics that add resources, effects, or automation opportunities |

Treat every attempt as an experiment rather than a race. Unlocking one new mechanic is often worth more than several small upgrades to a resource you already produce in bulk, because a new mechanic changes the rules of the next run, while a multiplier only changes a number.
